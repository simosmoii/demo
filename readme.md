# “拍鸟识鸟”轻量级地区鸟类识别系统

## 1. 核心功能

*   **拍照识鸟（即时识别）**：
    *   用户可以上传本地鸟类图片或直接拍照。
    *   系统使用预训练的 MobileNetV3 模型进行快速推理，识别出照片中的鸟类。
    *   支持识别 275 种不同的鸟类。
    *   展示识别结果（鸟类名称）及模型的识别准确率。

*   **智能定位**：
    *   集成高德地图 Web API。
    *   在用户上传照片时，系统会自动获取用户当前的地理位置（省、市），方便记录鸟类发现的地点。
    *   支持用户手动输入或修改地理位置。

*   **鸟类百科查询（科普详情）**：
    *   **自动展示**：针对识别出的鸟类，系统会自动在结果下方加载并展示其详细的百科信息。
    *   **独立查询**：提供专门的“鸟类百科”页面，用户可以输入鸟类名称（支持模糊搜索，如输入“白头海雕”），系统会自动检索并展示该鸟类的详细科普资料。
    *   **随时回顾**：在“历史记录”和“拍友鸟迹”中，用户也可以随时点击鸟类名称或“查看详细信息”按钮，通过弹出的详情模态框进行回顾学习。
    *   信息内容包括：形态描述、栖息环境、食性以及维基百科的拓展阅读链接。

*   **拍友鸟迹（社区共享）**：
    *   系统会将用户的每一次成功识别记录（图片、结果、位置、时间）匿名上传并持久化保存到服务器数据库中。
    *   提供“拍友鸟迹”公共画廊，所有用户都可以浏览他人拍摄的鸟类照片和记录，形成轻量级的观鸟社区。
    *   支持搜索功能，用户可以通过输入鸟类名称（支持模糊搜索）来查找特定的鸟类发现记录。

*   **个人历史记录（本地留存）**：
    *   系统采用免登录设计，用户的识别历史会自动保存在浏览器的本地缓存（LocalStorage）中。
    *   在“拍照识鸟”页面下方会展示用户的近期历史记录，方便用户随时回顾自己拍过的鸟类。

*   **同类发现推荐**：
    *   当用户成功识别出一种鸟类后，系统会在结果页下方展示其他拍友在哪些地方也发现了同一种鸟类，增加用户的互动感和探索欲。

*   **交互增强体验**：
    *   **图片放大与缩放**：在任何画廊（历史记录、拍友鸟迹）中点击图片，即可在弹出的全屏模态框中查看高清大图。支持鼠标滚轮在原位置放大缩小，也支持使用屏幕上的控制按钮进行缩放。放大后支持拖拽平移图片。
    *   **响应式设计**：界面兼容 PC 端和移动端，确保在不同尺寸的设备上都有良好的浏览体验。

## 2. 数据管理功能

*   **内置轻量数据库**：使用 SQLite 存储公共的识别历史，无需额外部署大型数据库，降低了系统的运行门槛。
*   **JSON 数据驱动百科**：鸟类的科普资料独立存储在 `bird_details.json` 文件中，方便后期由管理员或生态专家随时扩充和修改，无需修改业务代码。
